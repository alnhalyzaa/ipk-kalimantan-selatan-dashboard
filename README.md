# ipk-kalimantan-selatan-dashboard
Interactive dashboard untuk mengeksplorasi nilai IPK Kabupaten/Kota di Kalimantan Selatan berdasarkan tahun dan wilayah.

Tools: Looker Studio · Google Sheets

Fitur:
Filter tahun
Perbandingan kabupaten/kota
Tren IPK
KPI/summary
Visualisasi indikator
